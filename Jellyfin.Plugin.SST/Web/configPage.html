TV and other devices

Android TV, Google TV, Apple TV, Roku, webOS and Tizen apps do not load Jellyfin Web, so SST cannot put its menu inside them. These options let you drive those devices from a phone or PC instead.
On your phone or PC, SST offers to find subtitles for whatever your TV is playing.

Automatic download

Off by default. When enabled, the server searches for a subtitle each time playback starts without one and downloads the best match unattended. This runs on the server and calls out to your subtitle providers.

Subtitle Provider

SST uses Jellyfin's built-in subtitle provider system. To search and download subtitles, you must install and configure a subtitle provider plugin (e.g., Open Subtitles) from the Jellyfin plugin catalog.
SST does not store any subtitle provider credentials. Each provider plugin manages its own authentication.
